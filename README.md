# Black Tap Bar Book

Phone web app for the Black Tap Soho bar team: 130 drink specs with step-by-step picture guides, allergens, spec practice and a trial night tally.

Open it at https://rickdsage.github.io/bar-book/ and add it to your home screen (Safari: Share, then Add to Home Screen).

Specs marked "proposed" and every "suggested" price still need manager sign-off. Always use the venue's allergen matrix as the final word.

`index.html` is a single self-contained file built from the drink data in the Black Tap Drinks project.
